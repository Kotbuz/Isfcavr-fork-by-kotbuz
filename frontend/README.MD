# #Electron app - React + TypeScript + Vite

# Start app local

### Run commands:

```
# Переменные VITE_* — в корневом .env (см. .env.example в корне репозитория)
cd frontend
npm install
npm run dev
```

# Requierements:

* NodeJS version: ^24.15.0

```
node -v
```

* NPM version: >= 11.12.1

```
npm -v
```
